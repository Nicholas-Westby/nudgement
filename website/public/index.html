02 / Under the hood

What happens
in a review.

Each evaluator sends Jev the relevant context and a set of focused questions. For a commit, that includes checking whether the message matches the diff.

  1. 01

    Give it context.

    A file, a diff, a commit message. nudgement gathers the relevant context and runs exact checks.

    draft + context
  2. 02

    Ask a focused question.

    TypeSafe’s Jev returns structured judgements. Does this message match the diff? Would this test catch a broken implementation?

    questions → judgements
  3. 03

    Make a better call.

    nudgement turns those answers into findings. You or your coding agent decide what to change, then review the next draft.

    findings → revision
*

A nudge is a reason to take another look. It isn’t proof of correctness, and it doesn’t rewrite your code for you.
